# Rotating Wireframe Dotted Globe

A responsive, interactive 3D wireframe globe built with React, Next.js, D3.js, and HTML5 Canvas. This project renders a dynamic Earth visualization with dotted landmasses and allows users to interact with it via mouse drag and scroll.

## Features

- **Interactive 3D Globe**: Drag to rotate and scroll to zoom.
- **Auto-Rotation**: The globe rotates automatically when not being interacted with.
- **Dynamic Dotted Landmasses**: Uses GeoJSON data to dynamically generate a halftone dot pattern across all land features.
- **Responsive Canvas**: Automatically scales and resizes based on the user's screen dimensions.
- **Modern Tech Stack**: Built with Next.js (App Router), TypeScript, Tailwind CSS, and D3.js.

## Tech Stack

- **Framework**: Next.js
- **Visualization**: D3.js
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Vercel
